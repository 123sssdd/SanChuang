一、技术栈（Spring Boot后端）
核心框架：

Spring Boot：作为后端主框架，简化配置和开发流程，适用于RESTful API开发。

持久层：

Spring Data JPA/MyBatis：负责数据持久化，简化数据库操作。

安全认证：

JWT（JSON Web Token）：用于用户身份认证与会话管理。

Spring Security：实现权限控制和接口安全。

接口通信：

RESTful API：与前端采用HTTP协议交换数据。

WebSocket：支持实时消息推送与聊天室功能。

其他集成：

文件存储模块：用于设计作品图片等文件的上传与存储。

区块链节点：实现作品版权存证（将作品信息加密上链，生成数字指纹）。

支付模块：集成第三方支付服务实现交易结算。

二、主要功能点

用户管理（user模块）

注册、登录、用户信息维护

用户权限与角色管理

用户状态控制（如禁用、激活）

作品管理（product模块）

作品发布、编辑、删除

作品详细信息查询

作品版权上链存证

评论与互动（comment模块）

作品评论、留言

评论审核与管理

订单管理（productOrder模块）

作品交易订单生成与管理

支付接口集成

收入统计与订单状态跟踪

支付功能（paymentPay模块）

订单支付/退款操作

支付结果异步通知

实时通信（chatList/chatMessage模块）

聊天室功能

即时消息推送

自动重连与心跳检测

区块链版权保护

作品信息加密上链

生成唯一数字指纹

司法场景电子证据支持

其他功能

统计、数据可视化

平台审核、交易数据展示

AI智能助手接口（为前端提供AI问答等辅助功能）


三、特色说明

项目定位于设计交易与资源共享，针对设计师的版权保护需求，后端整体架构注重安全性、可扩展性及多模块协作。

后端为前端 Vue 应用提供完整的数据支撑，API接口严格分层，支持高并发与实时通讯。

结合区块链、AI、WebSocket等新技术，提升平台创新力和用户体验。
